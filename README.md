# Tracer Releases

Public Android APK releases and the update feed for Tracer. Application source is maintained in a separate private repository.

Download the APK from [the latest release](https://github.com/jerdonlee/Tracer-Releases/releases/latest).

After installing the first version with the updater, use **Settings → App updates → Check now → Download update → Install update**. Android may ask you to allow installations from Tracer; return to Tracer and choose Install update after granting it.

Update feed: `https://github.com/jerdonlee/Tracer-Releases/releases/latest/download/latest.json`

Install an update without clearing app data to retain device enrollment. Releases include the APK, update manifest and SHA-256 checksum. No app source, account credentials or signing keys are published here.
